# 文献对照说明

本文件记录 FeL_opacity 示例与已通读文献的对照边界。完整逐篇笔记见 [`../../refs/mds/reading_notes.md`](../../refs/mds/reading_notes.md)。

## 1. 本示例条件

- 数据来源：FeL 单节点 CRM 产物，0D 光薄模型。
- 电荷态：Fe XVII–XIX（由 `nele=8/9/10` 对应）。
- 温度：t00–t06，`temperatures.csv` 的 `T_K` 列实为 eV，约 272–2165 eV。
- 默认谱段：10–18 Å（约 0.69–1.24 keV），步长 0.002 Å。
- 基线物理：束缚-自由 PI（来自 `data/Fe0{8,9,10}a.rr` 的 6 点截面）+ 可选束缚-束吸收。

## 2. 可对照文献与用途

| 文献 | 对照内容 | 能否数值比对 | 本示例用途 |
|---|---|---|---|
| Bailey 2015 Nature | 6–16 Å、7–13 Å 的 Fe-L 实验不透明度；模型低 30–400% | 否，无机器可读谱表 | 谱段和准连续体偏低问题的定性背景 |
| Nagayama 2019 PRL | Cr/Fe/Ni 系统比较；Fe 在 >180 eV 短波准连续体低 30–45% | 否 | 判断偏差来源时不能简单归因仪器 |
| Jin 2009 ApJ | DLA 透射谱，800–980 eV L→M、990–1320 eV L→N/O | 仅 Table 1–4 可人工核对 | 吸收带位置与线型/轨道弛豫注意事项 |
| Zhang 2012 Phys. Plasmas | 150–1200 eV、T=72±4 eV 的 L+M 吸收谱 | 否 | 宽能区谱形参考 |
| Zhao 2024 J. Phys. B | BPRM vs FAC/RDW 背景 PI 一致，高能到约 500 Ry | 仅能级表可人工核对 | 支持 FAC 扭曲波 PI 作为输入 |
| Zhou 2026 arXiv | CI + plasma screening 使 Fe-L 不透明度增强 25–30% | 否 | 提示基线单组态/DW 可能低估稠密等离子体不透明度 |

## 3. 不可直接比对的原因

1. 文献多为高密度 LTE 或 Z-pinch 实验；本示例是光薄 CRM，没有辐射转移自吸收。
2. 本示例仅包含 Fe XVII–XIX，未求解完整电离平衡；文献常含多电荷态混合。
3. 文献无公开机器可读逐点透过率/不透明度谱，只有图件与少量表格。
4. 默认 10–18 Å 与 Zhou 2026 的 1200–1600 eV（约 7.75–10.33 Å）仅部分重叠，需在图注中说明。

## 4. 结论口径

本示例不声称与文献自动回归通过；仅记录“谱段重叠、吸收带位置、增强区间、方法学合理性”四类定性对照。任何数值偏差先检查数据映射、插值、单位、布居归一和丰度来源，不直接归因物理实现错误。
