# 公式核查规则

## 1. 证据优先级

1. 源码实现：核心函数、输出器、单位换算、参数顺序。
2. 生成文件头与实测记录：变量单位、块结构、输出字段。
3. 项目文档：`doc/manual.tex`、`doc/papers/`、`README.md`。
4. 历史注释：只在与源码一致时采信。

论文或手册出现但源码未直接命中，只能标为“间接依据”，不能写成源码已实现。

## 2. 核查步骤

1. 提取 README 中所有公式与紧邻的单位说明。
2. 将公式拆为可定位对象：函数名、宏名、输出字段、单位换算常数。
3. 在对应目录源码中定位实现或输出器。
4. 核对系数、符号、索引、单位、积分限与归一化因子。
5. 记录证据路径与短说明。
6. 若未找到源码依据，执行下划线注记规则。

## 3. 下划线公式规则

当源码中找不到该公式或实现依据时，直接把公式写成以下形式：

```latex
\underline{$<formula>$}
```

要求：

- 下划线直接包裹原公式的 LaTeX 内容，不另写说明性文字。
- 源码已溯源的公式保持普通 LaTeX 展示，不加下划线。
- 禁止 `<u>...</u>` 与 `\underline{\text{...}}` 形式的说明性注记。
- 维护报告中列出所有源码未溯源公式即可，不需要额外下划线说明清单。

## 4. 常见核查点

- 能量：ASCII eV 与二进制 Hartree。
- 截面：CE 含 π、EII 无 π；单位是否为 $10^{-20}\,\mathrm{cm^2}$。
- 谱强度：`strength` 随 `TYPE` 变化，photons/s 与能量发射率不同。
- AI/DC：率单位 s$^{-1}$，DC 强度是否为 $10^{-20}\,\mathrm{eV\,cm^2}$。
- 偏振：$a/b$ 的张量定义，不等同于初等强度比。
- 归一化：Maxwell 分布、Legendre 递推、QED 前因子。

## 5. 报告格式

| 公式 | 证据状态 | 证据位置 | 处理 |
|---|---|---|---|
| 公式简述 | 源码已实现 / 源码未找到 / 间接依据 | 文件与符号 | 无需注记 / 已加下划线 |
