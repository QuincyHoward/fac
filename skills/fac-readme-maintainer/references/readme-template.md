# README 统一模板

每个受管理目录的 `README.md` 优先采用以下结构。内容不足时保留标题并写“暂无”或“不适用”，不要删除关键章节。

```markdown
# <目录名> README

## 1. 定位与职责
说明本目录在 FAC 工程中的位置、边界和与其他目录的关系。

## 2. 文件与目录清单
逐项说明脚本、源码、配置、基准或子目录；路径使用相对路径。

## 3. 从底层读取到的依据
记录读取顺序、关键函数/宏、输出器、调用关系与证据路径。

## 4. 物理功能与公式
列出公式、单位、系数和索引约定。源码未命中的公式按规则加下划线注记。

## 5. API / 调用链
说明 PFAC、SFAC 或脚本入口如何落到核心实现，必要时使用 Mermaid 图。

## 6. 输入与输出
列出输入文件、输出表类型、字段与单位；说明哪些产物参与回归。

## 7. 验证与回归
说明如何运行检查、结果如何判读、无基准时如何做物理合理性检查。

## 8. 已知限制
记录非线程安全、死键、版本差异、弱线容差、注释与代码不一致等限制。

## 9. 导航
链接父目录、相关目录、skill 或工具和根 README。
```

## 写作规则

- 中文说明，术语、命令、文件名保留原文。
- 先事实后结论；关键结论附路径或符号证据。
- 完整公式使用 LaTeX 展示；源码未溯源公式直接写成 `\underline{$<formula>$}`，不另加说明性注记。
- 不写死机器绝对路径；外部工作目录使用 `<WORK_ROOT>`。
- 示例要抽象为原型，不绑定单一算例。
- 代码围栏和 Mermaid 图必须闭合。
