# 验证门禁

## 1. 覆盖性

- 列出所有受管理目录。
- 每个受管理目录存在 `README.md`。
- skill 目录同时存在 `SKILL.md` 与 `README.md`。
- 场景目录存在 `README.md`、`scene.json`、`run.py`。

## 2. 结构一致性

- README 使用统一模板或明确说明为何省略章节。
- 代码围栏成对闭合，Mermaid 块闭合。
- 相对链接存在，无断链。
- 不在文档中写死已移动工作目录名称。

## 3. 公式与证据

- 完整公式使用 LaTeX 展示格式。
- 源码未溯源公式直接使用 `\underline{$<formula>$}`。
- 无 `<u>...</u>`、无 `\underline{\text{...}}` 说明性注记。
- 源码已溯源公式未加下划线。
- 单位、系数、索引与源码/输出字段一致。

## 4. 内容质量

- 示例描述抽象到物理原型，不绑定单一案例。
- 输入输出与回归方式明确。
- 已知限制不遗漏非线程安全、死键、无基准、弱线容差等常见项。
- 父目录 README 已纳入子目录导航。

## 5. 工具与协议

- 所有 skill 通过 `quick_validate.py`。
- `mcp_server.py --help` 与 `--mode selftest` 可运行。
- `scripts/*.py --help` 可运行。
- 场景清单与锚点可解析。
- `.gitattributes` 中默认 LF，批处理文件例外为 CRLF。

## 6. 报告

最终报告必须包含：目录清单、更新清单、公式核查清单、下划线注记清单、未解决项。
