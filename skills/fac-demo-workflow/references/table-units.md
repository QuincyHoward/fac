# 输出表单位与列语义

## 1. 能量单位

- ASCII 输出表中的 `ENERGY`、`E0`、`Delta E`、`EGRID`、`TEGRID` 通常已是 eV。
- 二进制表内部通常使用 Hartree；不要对 ASCII 再次乘 27.2114。
- 遇到能量字段先查对应读取器与 verbose 输出路径，确认是否已乘 `HARTREE_EV`。

## 2. 截面与碰撞强度

- 碰撞强度 `Ω` 无量纲。
- CE 截面含 π 因子；EII 截面通常无 π 因子。移植公式时必须区分。
- 部分表的截面以 $10^{-20}\,\mathrm{cm^2}$ 输出；按表类型核对，不统一套用 $\pi a_0^2$。

## 3. AI / DC / DR

- AI 率为 s$^{-1}$。
- DC 强度常见单位为 $10^{-20}\,\mathrm{eV\,cm^2}$，不是无量纲。
- AI/DC 表不等于完整 DR 速率系数；完整 DR 需要辐射率与分支比。

## 4. 谱表与 CRM

- `SpecTable` 的 `TYPE=0` 布居块：`strength` 是能级布居 $N_i$，无量纲。
- `TYPE≠0` 线发射块：`strength` 是 $N_iA_{ij}$，单位 photons/s，不含 $h\nu$。
- 若比较能量发射率，必须再乘跃迁能量 $h\nu$。
- `read_sp()` 的键名存在历史误命名：前六列的实际语义与键名不完全一致；以表定义和源码为准。
- `RateTable` 含辐射、AI、CE、CI、RR 等贡献；温度与密度单位按表头解释。

## 5. 偏振

- `pop.txt` 表示磁子能级布居，列含义按输出器定义。
- `pol.txt` 末两列常给出 $a$、$b$，偏振度相关量为 $a/b$。
- $a/b$ 是球张量比，不等同于初等 $(I_\parallel-I_\perp)/(I_\parallel+I_\perp)$；不要混用定义。

## 6. 判读顺序

1. 读文件头，确定表类型、`NBlocks`、`TYPE`。
2. 确认 ASCII/二进制单位差异。
3. 对照读取器列名与源码输出逻辑。
4. 再做物理趋势与数值比对。
